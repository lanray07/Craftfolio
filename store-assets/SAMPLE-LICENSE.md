# Original samples

The simple sample PDF text and layouts generated by `StoreFixtureTest` and `JourneyTest`, and the Craftfolio book icon vector, were authored for this project. No third-party pattern PDF, photograph or designer content is included in the screenshot data.

The sample pattern/worksheet text and layouts are dedicated to the public domain under CC0 1.0. This dedication does not apply to the Craftfolio name, application code or third-party software dependencies. The samples are generated only by instrumentation and are not silently imported into a release installation.

Store screenshots show those original samples and fictional project notes. Personal imported files are not bundled into the APK or distributed through the store-assets package.
